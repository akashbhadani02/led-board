Quick start

  1. Upload the Arduino sketch to ESP8266 after entering Wi-Fi name/password.
  2. On this computer, run npm install once and then npm start inside the project folder.
  3. Open http://localhost:3000 on the PC. On mobile, use the PC's LAN address shown in the terminal, e.g. http://192.168.1.20:3000.
  4. Mobile/PC and ESP8266 should be on the same local Wi-Fi network. Permit Node.js through Windows Firewall if asked.
